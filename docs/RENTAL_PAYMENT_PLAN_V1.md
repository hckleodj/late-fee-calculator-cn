## 最终行为与金额定义

- 固定月租 = 车辆方案金额 / 期数 + 车辆方案金额 × 内部月费率。
- 租金总额 = 车辆方案金额 + 车辆方案金额 × 内部月费率 × 期数。
- 预付租金仅抵扣前几期，不扣减计价基础；押金按整数月录入，默认2个月，金额按固定月租折算，既不计入租金，也不抵扣租金。
- 原首付比例输入已替换为预付租金月数输入，默认0个月，未重复新增首付字段。押金保留按月填写，默认2个月。两项均接受非负整数月，预付月数不能超过租赁期限。
- 按月租倒推模式现在倒推车辆方案金额，向下取到分，保证不超过预算；不再产生“建议首付”。切换回报价后可直接使用并修改倒推金额。
- 本板块客户方案统一使用固定月费率租赁口径，不提供等额本息租赁确认单。底层原有平息、等额本息、倒推函数与历史结清逻辑均保留，历史客户功能不变。
- `calculationResult` 是内部结果真源；`paymentSchedule` 是该结果中不可变数组的引用。摘要、文本、付款计划、PNG、PDF 均读取它；客户模板显式白名单排除费率、全部总额、余额、手机号等内部数据；客户只显示月租、期数、押金/预付月数和逐期付款安排。
- 利用既有平息函数校验结果；新计划使用十进制整数有理数计算舍入边界，所有分配和合计为整数分。前 N-1 期使用固定月租，最后一期补齐尾差。
- `计划租金合计 = 租金总额`；`实际应付合计 = 租金总额 - 预付租金`。预付租金按固定月租乘以预付月数折算；预付覆盖整个租期时，以含末期尾差的准确金额抵扣，确保不多收或少收。
- “剩余计划租金”仅保留在内部数据中，用于分币核对；客户摘要、客户文字、计划表、PNG和PDF均不显示剩余租金、租金总额或任何全期合计。
- 金额最多2位小数、月费率最多6位小数、期限1至120期；车辆金额及租金总额上限1亿元。异常输入立即撤销旧结果和预览，不能导出旧方案。
- 方案编号在结果变化时更新，未变化时保持稳定；PNG/PDF使用同一编号。当前方案不持久化，页面已提示刷新后需重新录入。

## 导出实现

- 固定 HTML/CSS 模板；本地打包 html2canvas 1.4.1 与 jsPDF 4.2.1，无 AI 图片生成，也不向第三方上传客户数据。
- PNG 固定宽1588像素（2倍渲染），含完整期次。PDF A4，每页最多36期，表头及方案信息重复，最后一页包含合同约定文字及签名栏，不显示全期合计。
- 若长名称等导致页面过高，PDF 自动减少每页期数，优先保证文字可读；不截断表格行。当前 PDF 为清晰栅格内容，不提供可选中文文本层。
- 导出过程中快照被修改则拒绝下载旧结果；失败显示错误，不报成功。提示“发起下载”并要求在系统文件管理中核验，不宣称文件一定已保存。
- 手机预览可横向滑动；PNG 可在相册/图片查看器缩放阅读。主力手机实际下载仍待验收。
