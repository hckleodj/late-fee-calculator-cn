# 隐性开销与限制检查表

任何技术路线决定前，先把本表逐项报给用户，不得只比较开发速度。

## 当前 CloudBase 环境实况（2026-08-01）

- 当前必须支付：0 元。
- 当前套餐：免费体验版，上海地域。
- 到期时间：`2027-02-01 23:59:59`。
- 自动续费：未开启。
- 到期后价格：待到期前按腾讯云当时的官方控制台实时确认，不在仓库中写死历史价格。
- 不续费或环境被停用时：正式网页可能仍能显示静态界面，但登录、客户数据、提醒、收款、迁移和备份等云端功能将不可用。
- 数据迁移成本：已有 JSON 备份导出能力，可迁移业务数据；更换平台仍需要重做后端接口、权限配置和部署验证。
- 当前额外风险：数据库回档能力未开启，必须依赖定期 JSON 备份；如将来购买回档、独享数据库、自定义域名或更高配额，会产生新的费用，购买前必须再次确认。

## 云端网页版 / PWA

- CloudBase 免费额度结束后的套餐或按量费用
- 数据库容量、读写次数、云函数调用次数与运行时长
- 静态托管存储和下行流量
- 自定义域名购买、续费和 HTTPS
- 中国大陆公开网站可能涉及的ICP备案与主体资料
- GitHub Pages 在部分网络下的速度和可用性
- 监控、日志、自动备份、异地备份和数据恢复演练
- 管理员密码遗失后的恢复流程
- PWA 在微信内置浏览器不能直接安装、iPhone需经Safari添加到主屏幕
- 网页推送和后台提醒能力弱于微信小程序或原生APP

## 微信小程序

- 主体注册、微信认证及可能的年度续费，以当时页面为准
- 备案、隐私保护指引、类目和可能的行业资质
- 云开发资源超额费用
- 审核周期、驳回修改和版本发布维护
- 客户资料处理、权限和合规成本

## 原生 APP

- 苹果和安卓开发者账号、证书、签名与续费
- 应用商店审核、隐私材料和版本上架
- iOS、Android和电脑后台的多端适配维护
- 推送服务、崩溃监控、安装包分发和强制更新机制
- 同样需要云数据库和后端，不会因为做APP而省掉服务器成本

## 每次决策必须给出的四项

1. 当下必须支付的费用。
2. 免费期结束后的续费或按量价格。
3. 不付费时会失去的功能或可用性。
4. 将来换平台的数据迁移和重新开发成本。

平台价格和政策会变化。没有在当次决策中打开官方控制台或官方价格页核对时，必须明确标注“待实时确认”，不得把历史价格当成当前事实。
