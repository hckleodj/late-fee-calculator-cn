# 微信小程序与 CloudBase 部署清单

## 1. 当前未配置值

正式联调前必须替换：

- `project.config.json` 中的 `touristappid`
- `miniapp/config.js` 中的空 `envId`
- 云函数环境变量 `ADMIN_OPENIDS`

这些值不提交真实凭据到公开仓库。

## 2. 微信开发者工具

1. 使用小程序管理员微信登录微信开发者工具。
2. 在项目详情中填入真实小程序 AppID。
3. 选择或新建云开发环境。
4. 将环境 ID 写入 `miniapp/config.js`。
5. 重新编译，确认首页不再显示“尚未配置云开发环境ID”。

## 3. 数据库

在云开发控制台创建以下集合：

```text
users
customers
contracts
repayment_plans
payments
deposits
app_settings
audit_logs
migration_jobs
```

按照 `cloudbase/collections.json` 创建组合索引。按照 `cloudbase/database.rules.json` 将全部业务集合设置为客户端禁止读写。

安全规则只约束客户端；云函数内部仍必须进行身份和 `ownerOpenId` 校验。

## 4. 云函数

1. 先执行共享模块同步：`npm run build:shared`。
2. 在微信开发者工具中选择 `cloudfunctions/api`。
3. 上传并部署，安装云端依赖。
4. 云函数运行环境选择 Node.js 20 或平台当前支持的稳定版本。
5. 设置超时为60秒。
6. 设置环境变量 `ADMIN_OPENIDS`，多个 OpenID 使用英文逗号分隔。

不要使用“第一个访问者自动成为管理员”的方式初始化权限。

## 5. 首次管理员身份

首次登录需要先取得管理员 OpenID，再写入云函数环境变量。OpenID 只能从可信云函数调用上下文取得，不接受前端表单手填作为授权依据。

## 6. 旧网页数据迁移

1. 在原 GitHub Pages 中进入“客户管理 → 数据备份”。
2. 复制完整备份文本。
3. 在小程序“设置 → 旧网页数据迁移”粘贴。
4. 点击“校验并预览”。
5. 核对客户、合同、账单、收款和控制总额。
6. 确认后导入。

重复的 `legacyId` 默认跳过，不覆盖已有云端数据。存在无法分配的旧收款时，系统阻止直接导入。

## 7. 上线门槛

正式扩大使用前必须完成：

- 正常还款完整闭环
- 逾期与部分还款完整闭环
- 中途结清完整闭环
- 撤销收款恢复验证
- 同一备份重复导入验证
- 非白名单微信访问验证
- 手机与电脑端控制总额一致性验证
- 云端备份导出与恢复预览验证

公开提交审核前，还需完成小程序隐私保护指引、主体认证、备案和相关服务类目/资质核对。
